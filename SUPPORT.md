# Support

Use [GitHub Issues](https://github.com/amnesia2k/sendlib-sdk/issues) for reproducible integration bugs, injection problems, type errors, documentation corrections, and feature proposals. Include the Nest SDK, Node SDK, NestJS, Node.js, and TypeScript versions plus a sanitized minimal reproduction.

Do not post API keys, module configuration, authorization headers, personal addresses, message bodies, attachments, or unsanitized responses. Report vulnerabilities through [SECURITY.md](./SECURITY.md).

This is an unofficial community SDK. SendLib accounts, quotas, billing, templates, delivery incidents, and service availability belong with SendLib's official support channels.
